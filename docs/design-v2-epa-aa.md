# Design v2: EPA/AAバランス（魚タンパク質割合プロキシ）

Generated: 2026-05-01
Status: APPROVED & SHIPPED
Supersedes: `docs/design.md`（EAAスコア v1）

## v1からの変更動機

v1（`design.md`）では「**必須アミノ酸（EAA）バランス**」を測定する設計だった。タンパク質の「質」を見るアプリ、という位置付け。実装後にユーザーから根本的な仕様修正の指示を受けた：

> EAAではなくEPA/AA比でした。端的に言うと、食事画像中のタンパク質だけをはかって、魚とそれ以外のタンパク質の比が三段階で示されることがポイントです。
>
> 参考: https://www.sportsepa.com/evidence/epa-aa.html

つまり本来の目的は **EPA/AA比**（血中脂肪酸の指標）であり、v1のEAAスコアとは別物だった。v2はこのEPA/AA比を**食事写真から推定可能な実用プロキシ**に置き換える設計。

## 何を測るか — 用語の整理

| 用語 | 定義 | 測定方法 |
|---|---|---|
| **EPA** | エイコサペンタエン酸（オメガ3脂肪酸） | 主に魚由来。血中濃度は脂質検査で測定 |
| **AA（アラキドン酸）** | オメガ6脂肪酸 | 主に肉・卵・乳由来。血中濃度は脂質検査で測定 |
| **EPA/AA比** | 血中のEPA濃度 ÷ AA濃度 | 心血管疾患リスク・抗炎症の指標 |
| **本アプリの代理指標** | **魚タンパク質 ÷ 総タンパク質**（割合 %） | 食事写真から推定可能 |

### なぜ「タンパク質割合」をプロキシに使うか

1. **写真から脂肪酸量を推定するのは不可能**: 調理法・部位・脂質含有量で大きく変わる
2. **タンパク質量なら推定可能**: Vision API + 食品成分表で食材を識別すれば量がわかる
3. **EPAは魚に特異的**: 魚を食べる量と相関するので、魚タンパク質の割合は EPA摂取量の合理的なプロキシ
4. **AAは肉・卵・乳に多い**: 非魚タンパク質を分母に含めることで EPA/AA バランスの方向性を捉えられる

これは厳密な脂肪酸比そのものではなく、**「魚を食べた割合」を3段階で可視化する目安**として運用する。

## 信号機の閾値

```
青信号 (good): 魚タンパク質 ≥ 50%   ── 魚中心の食事
黄信号 (mid):  25-49%                ── 混在、改善余地あり
赤信号 (bad):  < 25%                 ── 魚が少ない、EPA摂取不足の可能性
```

### 閾値の根拠（MVP暫定値）

医学文献での血中EPA/AA比の目安：
- ≥ 0.5: 一般健康ライン
- ≥ 0.75: 心血管保護
- ≥ 1.0: アスリート目標

これは**血中値**であり、食事中の魚タンパク質割合との変換式は確立していない。50% / 25% は以下の直感に基づく仮置き：

- 焼き魚定食（サバ100g + 米・味噌汁・漬物）→ 魚タンパク質割合 ≈ 80% → 青
- ハンバーグ定食（牛豚ひき肉100g + 米・サラダ）→ 魚タンパク質割合 ≈ 0% → 赤
- 寿司5貫 + 卵焼き → 魚タンパク質割合 ≈ 60% → 青
- 鶏唐揚げ + 切り身魚少量 + 米 → 魚タンパク質割合 ≈ 30% → 黄

**運用後に栄養学的エビデンスが出れば差し替え可能**: 閾値は `lib/standards.ts` の `FISH_RATIO_THRESHOLDS` 定数1か所のみ。スコアロジックは何も変えなくていい。

## 食品DBのカテゴリ設計

各食材エントリに `category` フィールドを追加：

```json
{
  "name": "サバ",
  "aliases": ["鯖", "さば", "塩サバ", "焼きサバ"],
  "protein_g": 20.7,
  "category": "fish"
}
```

| カテゴリ | 用途 | 例 |
|---|---|---|
| `fish` | **分子（numerator）** | サバ、サンマ、サーモン、ブリ、イワシ、マグロ、ツナ缶、エビ、イカ、タコ、ちくわ |
| `meat` | 分母（AA寄与） | 鶏、牛、豚、ベーコン、ハム、ウインナー |
| `egg_dairy` | 分母（AA寄与） | 卵、牛乳、ヨーグルト、チーズ |
| `plant_protein` | 分母（中立） | 豆腐、納豆、味噌、枝豆 |
| `other` | 分母（少量） | 野菜、米、麺、漬物、果物 |

**設計判断**: 練り物（ちくわ、かまぼこ、はんぺん）は `fish` カテゴリに含める。原料は魚のすり身であり、EPA源として扱える。

## 計算式

```
total_protein_g = Σ matched_food.protein_g  (全マッチ食材)
fish_protein_g  = Σ matched_food.protein_g where category == "fish"

fish_protein_pct = fish_protein_g / total_protein_g × 100

light = computeLight(fish_protein_pct)
      = "green"  if pct >= 50
      = "yellow" if pct >= 25
      = "red"    otherwise
```

**v1からの簡素化**: アミノ酸9種それぞれの充足率計算が不要になり、必要量計算（体重 × 基準値）も不要。**体重入力UIも削除**した。

## Vision Promptの変更

v1: 「曖昧な総称ではなく具体食材名にコミット」（「焼き魚」より「サバ」）

v2: v1の指示に加えて「**魚の種類を特定すること**が最重要」を追加。曖昧な場合のフォールバックは「サバ」を既定値に：

> 魚は写真の見た目（皮の色、形、身の質感）から最も可能性の高い種類を1つ選んでください。判別が難しい場合は「サバ」を既定として返してOKです（魚であることが分かれば十分）。

カテゴリ判定だけ正しければスコアは正確に出るので、種類の細かい正答率より「魚 or 非魚」の判定精度を優先。

## 既知の限界

1. **食品DBはサンプル（57品目）**: 文部科学省「日本食品標準成分表」の完全データに差し替えれば認識率は大幅に上がる
2. **写真の解像度依存**: 暗い・遠い・角度が悪い写真では誤認識が起きる
3. **EPA/AA比そのものではない**: 魚タンパク質割合はあくまでプロキシ。サプリ摂取・個人の代謝差は反映されない
4. **単一食事の評価**: 1日トータル・1週間トータルでの集計はしない（履歴機能なし）
5. **MVP閾値の妥当性**: 50% / 25% は栄養学的に検証されていない

## 将来の拡張候補

- **栄養学的エビデンスに基づく閾値**: スポーツ栄養学者と協議して数値を確定
- **履歴機能**: 1日/1週間の魚タンパク質割合の平均をトラック
- **食品DB拡充**: 文科省CSV → JSON変換、500品目超
- **EPA含有量の直接推定**: 食材ごとのEPA含有量データ（mg/100g）を追加すれば、より直接的な指標を出せる
- **多食事比較**: 「先週は青5回、今週は青3回」のようなトレンド表示
